# Primeiro comando para o Codex

Copie e envie o prompt abaixo ao Codex quando colocar estes arquivos na raiz do repositório.

## Prompt recomendado

Leia integralmente `AGENTS.md` e todos os arquivos em `docs/` antes de modificar qualquer arquivo.

Quero iniciar o MVP Flutter do projeto **Chega Junto**.

### Objetivo desta primeira tarefa

1. Verifique se já existe um projeto Flutter no repositório.
2. Se ainda não existir, crie a base Flutter na raiz, preparada para Android e Web.
3. Estruture o projeto seguindo `docs/ARCHITECTURE.md`, sem criar complexidade desnecessária.
4. Configure o tema base e os tokens iniciais conforme `docs/DESIGN_SYSTEM.md`.
5. Prepare a navegação para as telas descritas em `docs/USER_FLOWS.md`.
6. Crie apenas placeholders técnicos mínimos para rotas que ainda não possuem screenshot.
7. Não invente o design final das telas.
8. Utilize dados mockados.
9. Não implemente backend, autenticação real, MySQL, OpenAI API, mapas pagos ou qualquer serviço externo nesta etapa.
10. Garanta que o projeto compile no Android e no Flutter Web.
11. Execute `dart format .` e `flutter analyze`.

### Importante

Vou enviar screenshots/protótipos das telas um por um.

Quando eu enviar uma imagem, implemente aquela tela com alta fidelidade visual, respeitando os componentes e regras do projeto.

Não altere telas já aprovadas sem minha autorização.

Ao final, informe:
- arquivos criados;
- estrutura resultante;
- como executar;
- qualquer ponto que dependa dos próximos screenshots.
